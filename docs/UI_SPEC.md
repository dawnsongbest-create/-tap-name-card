# 「碰一下名牌」页面与交互规格

> 版本：RB-01 minimal sync v1.0｜日期：2026-08-08｜状态：Fast-track baseline applied
> 页面范围：P01—P26；P08 为 P1，P26 为 P2，P0 中均隐藏。  
> 关联：[范围](./MVP_SCOPE.md)｜[API](./API_SPEC.md)｜[测试](./TEST_PLAN.md)

RB-01 Gate 覆盖：FT-01 的 P04/P05 只展示 Apple Minimal / Magazine，底层六模板 registry
保持不变；P06/P09/P10/P11 进入 Alpha；P12—P17 进入 First MVP Launch；P07 Resume、P18
视觉导出、P20 Collection（若 launch validation 不要求）、P08 AI、P26 NFC 后置。历史页面
编号和状态规格继续保留。

## 1. 全局交互规则

- 底部导航仅“首页 / 相遇 / 我的”。P11 无底部导航。P08/P26 不出现在 P0 导航、首页或“我的”可见入口。
- 公开页匿名完整可见，不自动登录、不调用建号、不通知主人、不展示访客身份；只有收藏、认识等互动才打开 P25。
- 主按钮每屏最多一个视觉主操作；公开页主按钮固定“认识一下”。
- 页面标准状态：正常、加载（骨架且超时可重试）、空（原因+行动+一个主按钮）、网络失败、无权限、不存在、审核中、隐藏、频率限制、内容不可用。与页面无关的状态可明确为“不适用”，不能误用空白页。
- 写操作按钮进入 loading 并防重复；超时显示“正在确认结果”，先查详情/列表后再允许重试。
- 全局无障碍：安全区域、键盘避让、足够点击区、文字放大不溢出、对比度、不只靠颜色、图片替代描述、减少动态效果。
- 文案温和、中性，不使用“匹配成功、被拒绝、人气、粉丝、访客”等词。

### 1.1 M1.3 共享 PageState 基础

M1.3 提供以下 canonical PageState：

- `ready`
- `loading`
- `empty`
- `network-error`
- `forbidden`
- `not-found`
- `unavailable`

只有适合人工重新读取的 `network-error` 和 canonical `unavailable` 显示 Retry。retry 是
UI intent only；组件不得自行发起网络、CloudBase 或身份请求。unknown/invalid input
显示本地安全的 unavailable-looking fallback，但必须 `showRetry=false`，不得反射原输入
或产生业务 intent。

`ErrorCode` 与 PageState 不等价，页面/业务层按上下文决定展示状态。该组件是最小共享
基础，不是完整产品 UI、全局 skeleton 或 operation-state system。下面页面规格中的骨架、
timeout、结果确认、P25 登录引导和领域状态仍由首次真实消费者 Sprint 实现。

## 2. 页面规格

### P01 启动与路由判断（P0）

- 目的/登录/来源：解析冷启动、分享、Token 和内部深链；无需登录；来源为微信启动、分享卡片、小程序码、通知、收藏/相遇内部跳转。
- 结构/组件/操作：品牌轻启动、路由解析状态、失败重试；不放强制登录按钮。
- 数据/事件/跳转：读取本地会话与路由参数；公开 Token 直达 P11，通知/私密页才检查登录并转 P25；事件仅路由错误，不记录匿名身份。
- 状态：加载=短骨架；网络失败=公开路由可重试；不存在/隐藏/审核中=转 P11 对应不可用状态；无权限=私密深链解释并登录；空/频率不适用。
- 文案/频率/无障碍/验收：不得闪现登录；防重复路由；启动元素有语义；匿名分享链接全程不建号，错误参数不进入错误用户数据。

### P02 首页（P0）

- 目的/登录/来源：管理和递出当前名牌；需登录；底部导航、P10 返回、P25 登录后进入。
- 结构/组件/操作：无名牌价值区；草稿继续卡；有名牌时当前名牌预览、微信原生分享、切换、
  编辑、创建、待处理请求、最近相遇；小程序码/视觉图片入口在 Post-launch 前隐藏。
- 数据/事件/跳转：`accountGetMe/cardList/notificationList/encounterList`；`card_create_entry`；到 P03/P06/P07/P11/P18/P19/P13/P16。
- 状态：加载骨架；空分“无名牌/有草稿”；网络失败缓存+刷新；受限账号保留自有数据入口但禁发布/互动；当前卡审核中/隐藏显示解释；卡不存在刷新当前引用；频率只作用分享码等动作。
- 文案/无障碍/验收：“不知道怎么开口介绍自己？……”；卡片替代描述；不同账号状态的主操作正确，当前名牌切换后首页一致。

### P03 名牌类型选择（Post-MVP；Alpha 直接进入 Social Gallery）

- 目的/登录/来源：选择 SOCIAL/RESUME；需登录 ACTIVE；P02/P19 创建入口。
- 结构/操作：两张类型卡、说明、底部“你可以创建多张……”；主操作为选择后进入 P04。
- 数据/事件/跳转：本地类型枚举，必要时账号/上限检查；`card_type_selected`；P04。
- 状态：加载仅账号检查；空/审核中/隐藏不适用；网络失败允许展示静态说明但创建前重试；受限/达上限解释并回 P19；重复点击锁定。
- 无障碍/验收：类型不只靠图标区分；读屏读出用途；不在选择前要求资料，类型不会被模板混淆。

### P04 模板选择（FT-01 / Alpha）

- 目的/登录/来源：从 Launch Catalog 选择 Apple Minimal / Magazine；登录；P03 或编辑器更换模板。
- 结构/操作：大卡/双列预览、名称、风格、L1/L2、多图/动画标识；点卡进 P05；使用/更换为主操作。
- 数据/事件/跳转：`templateList`；`template_list_viewed/template_selected`；P05 或返回编辑器兼容确认。
- 状态：加载骨架；空=配置异常并提供重试；网络失败可用安全内置模板；无权限=账号受限；不存在=模板下线返回列表；审核/隐藏不适用；频率不适用。
- 无障碍/验收：预览图有说明，标识带文本；首发只见两个 Launch Catalog 模板；延期模板
  不可见但其底层 registry/binding 继续通过架构回归。

### P05 模板全屏预览（FT-01 / Alpha）

- 目的/登录/来源：不填资料先完整看模板；登录；P04。
- 结构/操作：真实手机比例、滚动、深浅示例、模块支持列表；主按钮“使用这个模板”。
- 数据/事件/跳转：`templateGet`；选用后 `cardCreate` 或回原编辑器执行兼容切换；到 P06/P07。
- 状态：加载骨架；网络失败/不存在返回模板列表；无权限/受限禁止创建；空/审核/隐藏不适用；提交频率/重复由 cardCreate 处理。
- 无障碍/验收：滚动焦点可达、动画可关；不要求填资料，类型不匹配拒绝，创建超时先查 P19。

### P06 社交名牌编辑器（Alpha）

- 目的/登录/来源：编辑 SOCIAL 草稿；登录 owner ACTIVE；P05/P02/P19/草稿恢复。
- 结构/操作：顶部返回/名称/保存态/预览/更多；35–45% 实时预览；视觉主体、昵称、介绍、标签、模块、排序、主题、隐私；主按钮“完整预览”。更多含重命名、换模板、复制、隐藏、删除。
- 数据/事件/跳转：`cardGetMine/cardUpdateDraft/cardDuplicate/cardHide/cardDelete`；上传适配；`card_editor_opened/card_previewed`；P04/P09/P19。
- 状态：加载骨架+本地恢复；空=新草稿默认内容；网络失败=“已保存在本机，联网后同步”；无权限/不存在退出；审核中=可继续编辑新草稿但说明公开版本；隐藏=允许编辑再提交；Alpha 冲突显示 basic revision protection 与重试，不要求复杂 merge/recovery-copy UX。
- 文案/无障碍/验收：头像非必填；长按排序有上移/下移兜底；字段限制、最多 10 模块/4 图/2 自定义文本；停止输入 2 秒、切模块、上传成功、后台、离页保存；不静默丢失。

### P07 简历名牌编辑器（Post-MVP）

- 目的/登录/来源：编辑 RESUME 草稿；登录 owner ACTIVE；路径同 P06。
- 结构/操作：职业昵称、当前身份、能力、技能、项目、经历、作品/链接、目的、联系方式设置；项目用子页/抽屉；主按钮“完整预览”。
- 数据/事件/跳转：同 P06 加 `contactListMine/contactSaveMine`；P04/P09/P22。
- 状态：与 P06 一致；项目/链接子表单失败保留输入；私密联系方式上传/审核失败单独定位。
- 文案/频率/无障碍/验收：至少一个技能或项目；项目≤5、经历≤8、链接≤10；私密微信/电话/邮箱不进入公开名牌对象；社交模块不能混入。

### P08 AI 表达助手（P1，P0 隐藏）

- 目的/登录/来源：用户主动整理当前字段；登录；P1 字段旁“帮我表达”。
- 结构/操作：输入、最多一问/轮、最多 3 轮、最多 3 候选；“使用这句/更自然/再短一点/重新生成”。
- 数据/事件/跳转：`aiAssistCardField`；`card_ai_assist_opened/card_ai_candidate_applied`；确认后仅本地写当前字段并走普通草稿保存。
- 状态：加载候选骨架；空=继续手写；失败保留原文；限频说明稍后重试；无权限/账号受限；其他内容状态不适用。
- 文案/验收：“不用组织完整句子……”；不自动覆盖/发布、不编造、不诊断、不发送联系方式/相遇/备注；P0 无可见入口。

### P09 完整名牌预览（Alpha）

- 目的/登录/来源：以公开渲染组件预览并提交；登录 owner；P06/P07。
- 结构/操作：“这是别人看到的样子”、全页滚动、返回编辑、主按钮“发布名牌”。
- 数据/事件/跳转：本地/`cardGetMine` 草稿；`cardSubmitReview`；`card_previewed/card_publish_submitted`；成功到 P10，校验失败回对应编辑字段。
- 状态：加载；空/必填缺失列出字段；网络失败保留草稿；无权限/不存在退出；审核中防重复并显示旧版是否仍公开；隐藏可重新提交；限频显示稍后重试。
- 无障碍/验收：与 P11 核心渲染一致；失败具体到字段/图片/链接；发布超时查询 card 状态。

### P10 发布成功（Alpha）

- 目的/登录/来源：确认审核提交/通过后的下一步；登录 owner；P09 或审核通知。
- 结构/操作：成功文案；设置当前、微信原生分享、回首页；小程序码/生成图片入口在
  Post-launch 前隐藏。
- 数据/事件/跳转：`cardGetMine/cardSetCurrent/shareGenerateMiniCode`；`card_publish_success`；P02/P11/P18。
- 状态：若仍 REVIEWING 明确“正在审核”而不谎称公开；网络失败可回首页；审核失败引导编辑；卡隐藏/不存在不提供分享；频率仅小程序码。
- 文案/验收：“你的名牌准备好了……”仅审核通过使用；设置当前不自动覆盖历史快照；分享打开正确名牌。

### P11 对外名牌浏览（Alpha）

- 目的/登录/来源：完整公开浏览；**无需登录**；首发来自微信原生分享 deep link、相遇或本人预览；码、视觉图片码与 Collection 来源在对应 Post-launch Gate 启用。
- 结构/操作：无底部导航；首屏视觉/昵称/介绍/1–3 标签/下滑提示；主按钮“认识一下”；
  首发次操作为分享、更多（举报/登录后拉黑）；Collection 入口按独立 Gate 启用。
- 数据/事件/跳转：`cardGetPublicByToken`；互动登录后 `collectionAdd`；`public_card_opened/scrolled/shared/card_collected/greeting_clicked`（匿名仅汇总）；P12/P24/P25。
- 状态：加载骨架；网络失败重试；不存在统一不可用但防 Token 枚举；首次审核中/隐藏/删除分别用安全文案；无权限不强制登录；allow 开关关闭时解释；操作频率提示。
- 文案/无障碍/验收：匿名完整可见、不建号、不通知、不记录主人可见访客；拉黑只关闭互动，不能让公开页错误依赖登录态；未相遇不得把联系方式设主操作；公共 DTO 无 OpenID/草稿/私密联系方式。

### P12 认识请求确认（P0）

- 目的/登录/来源：确认递出哪张已发布名牌；需登录 ACTIVE；P11“认识一下”。
- 结构/操作：对方摘要、自己的卡、切换卡、后果说明；主“递出我的名牌”，次“再看看”。
- 数据/事件/跳转：`cardList/greetingSend`；`greeting_confirmed/greeting_success`；成功回 P11/已发列表，缺卡到 P03/P06/P07。
- 状态：加载；空=无已发布卡，提供创建/继续草稿/暂时收藏；网络失败保留选择；无权限=自己卡/拉黑/对方关闭；目标不存在/隐藏；审核中的自己卡不可选；限频/重复显示已递出。
- 文案/验收：明确“对方会收到通知并决定是否接受并回赠”；发送不收藏、不相遇；超时查已发列表。

### P13 收到的认识请求详情（P0）

- 目的/登录/来源：接收者处理请求；登录 receiver；通知/收到列表。
- 结构/操作：对方完整快照、共同兴趣预览、发起时间；主“接受并回赠”；次“暂时忽略”“不接受”；举报/拉黑；无聊天输入。
- 数据/事件/跳转：`greetingGetDetail/greetingDecline/safety*`；`greeting_received_viewed/shared_interest_viewed`；P14/P24。
- 状态：加载；网络失败；无权限；不存在；PENDING 正常；RETURNED 显示已回赠并进 P16；DECLINED/CANCELLED/EXPIRED 只读；对方卡后续隐藏仍显示请求快照；频率/重复防护。
- 文案/验收：无已读、无催促；不接受后由发起方在“已发出的请求”看到“对方暂时没有接受这次认识请求”，不创建 PRD 未定义的拒绝通知；不能单独接受。

### P14 接受并回赠名牌选择（P0）

- 目的/登录/来源：执行唯一接受方式；登录 receiver ACTIVE；P13。
- 结构/操作：自己的已发布名牌列表，默认当前卡，确认后果；主“确认回赠”，次“再看看”。
- 数据/事件/跳转：`cardList/greetingReturnCard`；`card_returned/encounter_created`；成功 P16，无卡去创建后返回原请求。
- 状态：加载；空=创建/继续草稿；网络失败保留选择；无权限/拉黑；请求不存在/过期/非 PENDING；选择卡审核中/隐藏不可用；频率/重复时查询相遇结果。
- 文案/验收：“回赠后，你们会出现在彼此的相遇册中……”；原子失败不出现半完成；重复点击只有一个相遇；不改变当前名牌。

### P15 相遇册列表（P0）

- 目的/登录/来源：私密管理已回赠关系；登录；底部“相遇”。
- 结构/操作：最近排序、对方快照、昵称、共同兴趣、时间、联系方式状态、本人备注摘要；点入详情。
- 数据/事件/跳转：`encounterList`；无公开人气事件；P16。
- 状态：加载；空用 PRD 温和文案和“递出名牌”主按钮；网络失败缓存+刷新；无权限登录；快照存在但用户注销显示注销态；对自己隐藏不出现；BLOCKED 默认隐藏；频率不适用。
- 无障碍/验收：备注只来自本人；只有 RETURNED 数据出现；不展示关系数排名/人气。

### P16 相遇详情（P0）

- 目的/登录/来源：查看历史快照、共同点、本人备注和联系方式状态；登录 encounter 双方；P15/通知。
- 结构/操作：双方快照、共同兴趣、P0 首次事件、私人备注、联系方式入口、隐藏/拉黑/举报；“分享相遇”为 P1 隐藏。
- 数据/事件/跳转：`encounterGetDetail/encounterUpdateNote/encounterHideForMe`；`shared_interest_viewed`；P17/P24/P11。
- 状态：加载；网络失败保留非敏感快照；无权限/不存在；对方注销只显示历史快照；BLOCKED 清敏感操作；审核/隐藏只影响打开当前卡，不覆盖历史；备注保存限频/冲突。
- 文案/验收：备注≤500 且对方永不可见/不进 AI；共同兴趣只用允许字段；私密联系方式未通过不展示。

### P17 联系方式申请（P0）

- 目的/登录/来源：申请、处理和查看经确认的联系方式；登录 encounter 双方；P16/通知。
- 结构/操作：发起方选自己愿提供项；接收方处理时选自己愿提供项；状态区；接受/拒绝/撤回/撤销；接受后只显示双方选定内容。
- 数据/事件/跳转：`contactListMine/contactRequest*/contactGetShared`；`contact_request_sent/accepted/declined`；P22/P16。
- 状态：加载；空=无联系方式先去 P22；网络失败立即隐藏未确认敏感值；无权限=未 RETURNED/非 ACTIVE/拉黑；请求不存在；PENDING/ACCEPTED/DECLINED/CANCELLED/REVOKED；冷却显示可再试时间。
- 文案/无障碍/验收：“对方也会选择愿意提供的信息”；不得默认全选；撤销提示已复制内容无法收回；未选项永不返回。

### P18 视觉名牌图片生成（Post-launch）

- 目的/登录/来源：生成专门设计的视觉图片；登录 owner；P02/P10/P11 本人操作。
- 结构/操作：比例→内容→主题→预览→保存；小程序码可选；不自动保存。
- 数据/事件/跳转：公开快照、模板、`shareGenerateMiniCode`、Canvas；`card_image_generated/card_image_saved`；保存后停留/回来源。
- 状态：加载字体/图片；空=卡不可导出；网络失败允许已有资源无码导出；无权限/非 owner；审核中用旧公开版或明确不可用；隐藏/删除不生成；码限频；相册拒绝给设置说明。
- 无障碍/验收：3:4/9:16/1:1，六模板，中英/Emoji/长文不裁切；iOS/Android 保存；码失败可无码；预览图替代说明。

### P19 我的名牌列表（P0）

- 目的/登录/来源：管理多张草稿/名牌；登录；“我的”/P02。
- 结构/操作：按状态卡片、当前标识；创建、编辑、复制、设置当前、隐藏、删除、分享。
- 数据/事件/跳转：`cardList/cardSetCurrent/cardDuplicate/cardHide/cardDelete`；P03/P06/P07/P09/P11。
- 状态：加载；空=创建第一张；网络失败缓存；无权限/受限保留查看编辑必要数据但禁发布；审核中/失败/隐藏/删除分别显示；达到 10 张禁创建并解释；重复写先查列表。
- 无障碍/验收：任意时刻一张当前卡；回赠选卡不改变当前；逻辑删除不破坏历史快照。

### P20 收藏列表（First MVP 后段或 Post-launch）

- 目的/登录/来源：查看静默收藏；登录；“我的”。
- 结构/操作：快照、收藏时间、打开公开卡、取消；不可用卡显示缩略快照和说明。
- 数据/事件/跳转：`collectionList/collectionRemove/cardGetPublicByToken`；P11。
- 状态：加载；空说明用途+去浏览分享链接；网络失败缓存；无权限登录；目标不存在/隐藏/删除显示“这张名牌已经不可查看”；审核中按旧快照；频率/重复安全。
- 验收：名牌主人看不到收藏者/数量；取消不影响请求/相遇；打开使用当前公共可用性而历史缩略仍保留。

### P21 通知中心（P0 小程序内）

- 目的/登录/来源：业务通知与审核结果；登录；“我的”/首页提示。
- 结构/操作：未读/全部、通知卡、全部已读；点入具体业务页。
- 数据/事件/跳转：`notificationList/notificationMarkRead/All`；P13/P16/P17/P06/P07/P19。
- 状态：加载；空=暂无需要处理的信息；网络失败缓存摘要；无权限登录；相关资源不存在/过期显示安全结果；无审核/隐藏特殊页；批量重复安全。
- 验收：没有浏览/收藏/拉黑通知；认识请求 read 不反馈给发起方；订阅消息入口 P0 隐藏。

### P22 我的联系方式（P0）

- 目的/登录/来源：管理公开/私密联系方式；登录 owner；“我的”/P07/P17。
- 结构/操作：类型列表、公开级别、启用、添加/编辑/删除、二维码上传；默认 PRIVATE。
- 数据/事件/跳转：`contactListMine/contactSaveMine/contactDeleteMine`；返回 P07/P17。
- 状态：加载；空=添加联系方式；网络失败不丢表单；无权限/受限按政策允许必要自有管理；不存在；审核中/失败定位二维码或链接；上传/频率失败重试。
- 无障碍/验收：敏感值支持遮罩/显隐；删除后共享读取立即过滤；PUBLIC 仍需用户明确加入公开名牌且通过审核。

### P23 隐私与安全（P0）

- 目的/登录/来源：协议、隐私、拉黑管理、账号状态、注销；登录；“我的”。
- 结构/操作：协议版本、数据说明、拉黑列表/解除、注销影响与二次确认；不显示谁浏览/收藏。
- 数据/事件/跳转：`accountGetMe/safetyUnblock/accountDelete`；注销成功到 P01。
- 状态：加载；空=无拉黑用户；网络失败禁止在未知状态下重复注销；无权限登录；账号 RESTRICTED/DELETED 显示必要说明；其他状态不适用。
- 文案/验收：解除拉黑后，仅在双方均无拉黑时恢复相遇的 ACTIVE 交互能力，但旧请求和已撤销联系方式不恢复；注销明确公开入口、联系方式和历史快照影响；二次确认；注销超时先验证 Token/账号；必要安全留存不伪称即时物理删除。

### P24 举报页（P0）

- 目的/登录/来源：选择理由并保存证据；P11/P13/P16 入口；PRD 有“匿名可举报”与页面“需登录”歧义，M0 暂定入口匿名可见、提交触发 P25。
- 结构/操作：八类原因、可选描述、证据说明、提交；不展示处理后台。
- 数据/事件/跳转：`safetyReport`；提交成功回来源。
- 状态：加载目标摘要；空不适用；网络失败保留描述；未登录去 P25 后返回；目标不存在仍可在已有快照时提交；隐藏/删除也保留证据；限频中性提示。
- 无障碍/验收：原因不只图标；举报保存当时快照；对方不获举报者身份；产品需在 M1 前确认匿名提交策略。

### P25 登录引导弹层（P0）

- 目的/登录/来源：仅用户主动互动时解释登录；本身无需登录；P11 收藏/认识/举报提交及私密深链。
- 结构/操作：说明为何登录、协议/隐私确认；主“登录后继续”，次“暂时不要”；不得阻挡继续浏览。
- 数据/事件/跳转：`authEnsureUser`；成功返回原意图页/动作，取消回 P11。
- 状态：加载登录；网络失败可重试/取消；账号受限解释；协议缺失；其他内容状态继承来源；重复登录只建一个账号。
- 文案/无障碍/验收：不诱导、不默认勾选协议；关闭焦点返回原按钮；公开页打开时绝不自动出现。

### P26 NFC 设备管理（P2，P0 隐藏）

- 目的/登录/来源：未来绑定/解绑/停用动态入口；登录；P2 才在“我的”开放。
- 结构/操作：设备、模式、固定卡、解绑、丢失；保留二维码兜底说明。
- 数据/事件/跳转：`nfcResolve/nfcBind/nfcUnbind/nfcDisable`；固定卡选择 P19。
- 状态：加载、空设备、网络失败、无权限、设备不存在/已绑定/丢失、目标卡隐藏；频率与 Token 防枚举。
- 验收：P0 无入口、无请求、无假 API；NFC 不存个人资料；解绑/注销后原资料不可解析；上线前官方文档与真机验证。

## 4. 埋点与隐私

使用 PRD 第 36 章事件名。埋点只用于汇总漏斗，不向普通用户展示人气指标。匿名公开页事件不得包含可还原访客身份的数据，不得产生主人可见记录；私人备注、联系方式、OpenID、完整 AI 输入不得进入埋点属性。
