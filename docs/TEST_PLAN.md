# 「碰一下名牌」MVP 测试计划

> 版本：M0 v1.1（第二轮 Review）｜日期：2026-07-24｜状态：`IN_REVIEW`  
> 关联：[范围](./MVP_SCOPE.md)｜[数据](./DATA_MODEL.md)｜[API](./API_SPEC.md)｜[UI](./UI_SPEC.md)｜[任务](./TASKS.md)

## 1. 目标与范围

证明 P0 在身份、权限、状态、幂等、隐私、弱网和真机条件下形成唯一合法闭环：

```text
匿名浏览（无通知/无账号）
→ 可选静默收藏（无社交副作用）
→ 登录并选择已发布名牌递出
→ PENDING
→ 接收方原子“接受并回赠”
→ RETURNED + 唯一 ACTIVE encounter
→ 双方各自选择并确认联系方式
→ ACCEPTED（仅选中项可见）
```

P1 AI、相遇事件增强、订阅消息和 P2 NFC 不属于 P0 放行条件，只验证 P0 中无可见入口/无误调用。测试层级：单元、云函数集成、页面/组件、端到端、双账号手工、真机、staging 上线回归。

## 2. 环境、设备、账号和数据

| 账号 A | ACTIVE；协议已确认；发布 SOCIAL 卡 A-S1 和可选 RESUME 卡 A-R1；3 个联系人 |
| 账号 B | 初始匿名，后建立 ACTIVE；发布 SOCIAL 卡 B-S1；3 个联系人 |

固定夹具：

- 六模板及每个模板的最短/最长、中英混排、Emoji、四图、长链接内容。

所有测试数据显式标记环境；日志/截图不得包含真实手机号、微信二维码、OpenID 或密钥。

## 3. 放行门槛

- 格式、类型、单元和集成测试 100% 执行且无阻断失败。
- 核心状态机、权限策略、业务键和公共/私密字段投影分支覆盖。
- P01—P07、P09—P25 的适用状态通过；P08/P26 在 P0 隐藏。
- A/B 脚本在 staging 的 iPhone 与 Android 各至少完整通过一次。
- 分享、小程序码、图片保存分别真机验证；仅开发者工具通过不算完成。
- 无上线阻断项；未验证能力必须显式记录，不能标 DONE。

## 4. 单元测试

### 4.1 校验与模板

- SOCIAL：昵称 1–20、介绍 1–60、标签 1–8、视觉主体必需但真人头像非必需。
- 社交模块各字符/数量限制；总模块≤10、图≤4、自定义文本≤2。
- RESUME：昵称 1–30、身份 1–40、能力 1–80、技能或项目至少一项；项目≤5、经历≤8、链接≤10、项目简介≤500。
- 每个 `CardModuleType` 具体 Schema 拒绝未知/错误对象；链接、图片引用、替代文本校验。
- 六模板类型、版本、导出比例、模块兼容；切换模板保留不兼容内容并标“暂未展示”；配置错误安全回退。
- 未授权字体/角色素材清单检查。

### 4.2 状态机与键

- Card 合法/非法迁移；审核中新版不替换旧快照。
- Greeting 仅 `PENDING→RETURNED|DECLINED|CANCELLED|EXPIRED`，无 `ACCEPTED`。
- 只有 `PENDING→RETURNED` 触发 encounter。
- Contact 仅在 ACTIVE encounter：`PENDING→ACCEPTED|DECLINED|CANCELLED`，`ACCEPTED→REVOKED`。
- `requestKey/pendingPairKey/pairKey/collectionKey/blockKey` 确定、分隔安全；`pendingPairKey` 与 `pairKey` 对双方排序，`requestKey` 保留请求方向。
- 当前名牌最多一张；删除/隐藏当前卡的回退规则。

### 4.3 共同兴趣、错误与隐私

- 标准标签 ID、规范化自定义文本、相关标签映射可解释且可复现。
- 排除私人备注、联系方式、草稿、敏感经历、`matchEnabled=false`。
- PRD 错误码到安全文案；内部异常不透传。
- 公共 DTO 白名单快照测试；私密 DTO 只返回选中项；日志脱敏快照测试。

## 5. 云函数集成测试

每个 P0 函数执行 API_SPEC 的成功、身份、所有权、校验、状态、拉黑、幂等、频率、日志和失败行为。重点矩阵：

| 域 | 必测 |
|---|---|
| 身份 | 并发 `authEnsureUser` 只有一条 user；匿名 P11 不调用；OpenID 不返回 |
| Cards | C 不能读/改 A 草稿；上限并发；draft revision 冲突；公开 Token 不可枚举；隐藏/删除立即失效 |
| 审核 | 首发拒绝不公开；新版审核时旧版继续；通过时新快照原子切换；失败定位类别 |
| 收藏 | add 重放/并发一条；remove/恢复；无 notification/greeting/encounter 写入 |
| Greeting | 自己、无卡、未发布卡、关闭开关、拉黑、同向及反向重复、30 天过期；发送无收藏/相遇；拒绝不创建未定义通知 |
| 回赠 | 每个事务步骤失败均无半完成；并发只有 RETURNED/一个 pairKey/一组通知；已有 encounter 不覆盖首次快照 |
| Encounter | C 越权；双方视图；历史快照不随当前卡改变；备注只返回 owner |
| 联系 | 相遇前拒绝；他人联系人 ID 拒绝；接收方不选/选项；撤销/拉黑/注销后明文不返回 |
| 通知 | 去重；已读仅本人；无浏览/收藏/拉黑通知；相关资源过期安全显示 |
| 安全 | 举报证据快照；拉黑关闭待处理请求并 REVOKE 已接受站内联系方式；解除仅恢复无反向 block 的 encounter ACTIVE，不恢复旧请求/共享；注销先使入口与私密读取失效 |
| 分享 | owner/PUBLISHED；固定/当前入口；码失败安全降级；参数不暴露内部主键/OpenID |

## 7. 重复提交与事务失败

### 7.1 重复/并发

- 同 operationId 重放、不同 operationId 同时点击、客户端超时后重试、两个设备并发。
- 创建用户/卡、草稿、当前卡、收藏、Greeting、回赠、联系方式、拉黑、举报、注销。
- 断言唯一业务键文档/占位键、最终状态、通知数、快照数和可恢复性。

### 7.2 `greetingReturnCard` 故障注入

在以下每一步前/后中断：锁请求、验证卡、建回赠快照、改 RETURNED、upsert encounter、写双方快照、共同兴趣、首次 event、通知。预期：

- 若事务未提交：仍 PENDING，无 encounter/通知对外可见。
- 若已提交但响应丢失：详情为 RETURNED，唯一 encounter 和去重通知；重试返回同一结果。
- 永远不出现 `ACCEPTED` 或“已接受未回赠”。
- 若 pairKey 已存在：encounter 首次双方快照保持不变，本次双方快照只保存在 greeting，P0 不重复创建首次 event。

### 7.3 其他原子边界

- 设置当前卡并发：`users.currentCardId` 权威且至多一张。
- 审核通过失败：旧快照或新快照之一完整公开，不出现 pending 公开。
- 接受联系方式失败：状态和双方选择同时生效或都不生效。
- 拉黑/注销部分清理失败：block/DELETED 策略先阻止敏感读，后台可幂等续跑。

## 8. 页面状态测试

P01—P07、P09—P25 对适用状态逐项测试：

- READY、LOADING（骨架、超时）、EMPTY（原因+行动+主按钮）。
- NETWORK_ERROR（重试/缓存）、FORBIDDEN（解释）、NOT_FOUND。
- REVIEWING、REJECTED、HIDDEN、DELETED/UNAVAILABLE。
- RATE_LIMITED、SUBMITTING、防双击、UNKNOWN_AFTER_TIMEOUT。
- 返回/前后台/深链/会话过期/文字放大/减少动态/键盘/安全区。

专门断言：P11 进入时没有 P25；P08/P26 及 P1 相遇分享/订阅入口在 P0 不可见。

## 9. 弱网、草稿、上传与审核

### 9.1 草稿

1. 输入后 2 秒保存；切模块、上传成功、后台、离页保存。
2. 断网继续编辑显示“已保存在本机”；杀进程/重开恢复。
3. 恢复网络按队列同步；同 operationId 无重复。
4. 两设备基于同 revision 编辑触发冲突，服务器旧版可恢复，不静默覆盖。
5. 编辑 PUBLISHED 卡时公开 Token 始终显示旧快照。

### 9.2 图片

- 10MB 边界、支持/不支持格式、压缩、0/1/4/5 张、上传中离页、临时 URL 失效。
- 本地预览→上传→审核→云引用；失败保留本地选择并重试。
- 公开图片与私密微信二维码存储访问隔离。

### 9.3 审核版本

- 文本、图片、链接/二维码各自通过/拒绝/超时。
- 首次 REVIEWING 无公开内容；新版 REVIEWING 旧版继续；拒绝不替换旧版；通过新建不可变快照。
- 用户在审核期间继续编辑，不能改变已冻结审核内容。

## 10. 业务场景测试

### 10.1 匿名

- 从好友分享、群、码、视觉图片码打开完整 P11。
- 无账号记录、无主人通知、无已读/访客身份。
- 分享无需登录；收藏/认识/举报提交才 P25；取消登录仍可浏览。

### 10.2 收藏

- 允许/关闭、重复 add、remove/恢复；失效卡保留缩略快照。
- 前后统计 greetings/encounters/notifications 均无新增。

### 10.3 认识请求与过期

- B 无发布卡时看到创建/草稿/只收藏；有卡时明确选择。
- 发送保存 A/B 当时快照；不自动收藏；发出状态无已读。
- 暂时忽略不改状态；30 天任务/惰性检查到 EXPIRED；过期不可回赠；EXPIRED 时释放 `pendingPairKey`。
- 拒绝使用中性文案；发送方可取消；拉黑变 CANCELLED；所有离开 PENDING 的路径都原子释放 `pendingPairKey`。

### 10.4 相遇和共同兴趣

- 仅 RETURNED 生成；pairKey 两个方向一致；重复回赠不重复。
- A/B 历史快照后续编辑不变；当前公开卡可另外打开。
- 精确标准标签、规范化自定义、相关映射；排除禁用/私密字段。
- A/B 私人备注互不可见；C 不可读。

### 10.5 联系方式

- 未相遇、HIDDEN_FOR_USER（仅视图隐藏不改变 ACTIVE）、BLOCKED、非参与者、开关关闭。
- A 只选两项，B 接受只选一项；A 只看 B 的一项，B 只看 A 的两项。
- B 不能借请求读取 A 未选项；A 不能传 B 的联系人 ID。
- DECLINED 后 7 天默认冷却由配置改变；PENDING 可撤回；ACCEPTED 任一方撤销后双方小程序内不再取值。
- 已复制不可收回提示；删除/禁用联系人、拉黑、注销后实时过滤。

### 10.6 通知、安全与注销

- 正确的七类 P0 通知与去重；无浏览/收藏/拉黑通知；不向业务对方显示 read。
- 举报八类原因、描述限制、证据快照；目标修改/删除后证据不变。
- 拉黑关闭待处理 greeting/contact，将已接受联系方式变为 REVOKED，阻止新互动并默认隐藏 encounter；解除后仅在无反向 block 时恢复 encounter ACTIVE，不恢复旧请求或联系方式共享。
- 注销二次确认；Token、当前卡、联系方式立即失效；对方只见“该用户已注销”的历史快照。

## 11. 视觉图片、分享与真机

### 11.1 导出矩阵

六模板 × 3 比例 × 主题支持 ×（有码/无码）× 内容边界。验证：

- 1080×1440、1080×1920、1080×1080 像素。
- 中英、Emoji、长文本、1–4 图、透明/旋转图片、低内存。
- 不裁切、不溢出、不错误换行、不出现临时文件失效。
- 不自动保存；相册拒绝/永久拒绝/再次授权；失败可重试。

### 11.2 分享/码

- 固定名牌入口始终打开同一张卡；当前名牌入口切换后更新。
- Token/scene 不暴露 OpenID/内部主键且不可枚举。
- 好友、群、扫码冷启动/热启动；隐藏/删除/注销后不可用。
- 小程序码失败时分享仍可用、图片可无码导出。

### 11.3 真机记录

每次记录：构建版本、云环境、机型、OS、微信/基础库版本、账号、时间、结果、截图/视频位置、问题 ID。iPhone 与 Android 均完成 A/B 全链路，不以模拟器代替。

| 18 | B 再发起联系方式申请，A 再次明确选择并接受 | 双方再次只看到本轮选中项 | CR2=ACCEPTED；CR 保持 REVOKED |

| 20 | A 解除拉黑且 B 未拉黑 A | 相遇恢复可互动，但不恢复旧共享或请求 | block 失效；E=ACTIVE（A 的隐藏标记仍保留）；CR/CR2 仍 REVOKED；不新建 greeting |
| 21 | B 举报 A 卡（测试原因） | 提交成功，不显示处理细节 | report PENDING，引用 A1 证据 |
| 22 | D 完成相遇后注销（独立用例） | D Token/联系不可用；对方见注销快照 | user D=DELETED；cards/token/contact 失效；历史 snapshot 保留并标注销 |

脚本通过后核对集合计数、唯一键、通知类型/数量、日志脱敏和公共 DTO 快照。

## 14. 上线阻断

任一项存在即停止上线：

- 匿名被强制登录/建号或主人获得访客身份。
- 联系方式未经确认、未选项泄露、撤销/拉黑/注销后仍可读。
- 收藏产生通知/请求/相遇；非 RETURNED 创建相遇；重复请求/相遇/通知。
- 草稿频繁丢失；审核中覆盖旧版；未审核内容公开。
- 越权读写草稿、备注、联系人、内部身份；脚本/链接/上传风险。
- iOS/Android 核心闭环失败，分享/码错误，图片严重错位。
- 拉黑后仍可互动；注销后公开入口仍有效。
