# 使用顺序

1. 将本文件夹作为项目仓库根目录。
2. 在 GitHub 创建一个新的私有仓库，例如 `tap-name-card`。
3. 将本文件夹中的文件上传到仓库。
4. 使用 Codex 打开该仓库或本地文件夹。
5. 第一次将 `CODEX_FIRST_PROMPT.md` 的全部内容发给 Codex。
6. 审核 Codex 生成的规划文档，不要马上让它开发。
7. 规划通过后，再将 `CODEX_MILESTONE_1_PROMPT.md` 发给 Codex。
8. 每完成一个里程碑，先测试和验收，再进入下一阶段。

`/docs/PRD.md` 是唯一正式产品需求来源。
